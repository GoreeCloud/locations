# Native Locations privacy workspace

Flutter 3.27.4 / Dart 3.6.2. Native Linux desktop and Android targets, not WebView wrappers. From this directory: `flutter pub get`, `flutter analyze`, `flutter test`, `flutter build linux --release`, `flutter build apk --debug`. Android builds use a compatible JDK 17; no release signing is configured. Use synthetic data for development. No location permission is declared. INTERNET supports explicitly requested HTTPS history retrieval; cleartext traffic is disabled. Clipboard export requires confirmation; clipboard contents may be visible to other apps. No tracking or automatic account synchronization. Enter only a trusted server origin and use its access key for a bounded read-only request.
